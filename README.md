# Sytizen

Source repository for Sytizen, the fast modern web framework.

## Packages

Sytizen is split into multiple packages.

- [sytizen](./packages/sytizen): The fast modern web framework.
- [type-guard](./packages/type-guard): Runtime type guards so Sytizen (and consumers) can share safe, reusable narrowing helpers
